# موقع KFC Vinnytsia التجاري — واجهة عملاء + لوحة تحكم كاملة

موقع Static بالكامل (HTML/CSS/JS بدون Build) قابل للتخصيص الكامل من لوحة تحكم محمية.
البيانات الحقيقية للنشاط معبأة مسبقًا من لصقة Google Maps.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح (يعمل بدون سيرفر)، أو الأفضل عبر سيرفر محلي:

```bash
cd project
python3 -m http.server 8080
# ثم افتح: http://localhost:8080/index.html
# اللوحة:   http://localhost:8080/admin.html
```

## النشر (بدون Build)

المشروع Static — ارفع مجلد `project/` كما هو إلى:

- **Cloudflare Pages** / **Netlify** / **Vercel**: مجلد النشر = `project/`، أمر البناء = فارغ.
- **GitHub Pages**: ارفع محتويات `project/` إلى الفرع ثم فعّل Pages.

> لا يوجد `package.json` لأن المشروع لا يحتاج أي تبعيات أو بناء — يعمل مباشرة.

## أول دخول للوحة (`admin.html`)

1. أنشئ كلمة مرور المالك + 3 أسئلة استرداد مختلفة (لا توجد كلمة مرور افتراضية).
2. من تبويب **استيراد Google Maps** يمكنك لصق بيانات جديدة وتحليلها (ذكي: يحافظ على منتجاتك اليدوية
   وطلباتك وصورك، أو **استبدال كامل** عند الحاجة).
3. من تبويب **WhatsApp والتوصيل**: أدخل رقم WhatsApp ثم جرّب زر **اختبار WhatsApp**، وتحكم بالتوصيل
   (عام + لكل منتج: متاح / غير متاح / اتباع العام).

## المزايا المنفذة

- واجهة عملاء (عربي/إنجليزي/فرنسي، RTL/LTR): Hero + تقييم + منيو + بحث وتصفية + سلة عاملة + إتمام طلب
  + رسالة WhatsApp كاملة (تُحفظ أولًا ثم تُفتح `wa.me`) + خريطة Google + تواصل.
- لوحة تحكم: نظرة عامة (اكتمال الملف/العدادات)، معلومات، مظهر (11 لونًا + Presets + خطوط + تخطيط
  + ترتيب أقسام + أنماط Hero والبطاقات والأعمدة)، وسائط (رفع من الجهاز مع ضغط ومعاينة وتحقق)،
  منتجات وتصنيفات (CRUD ثلاثي اللغة)، طلبات (5 حالات)، تنبيه صوتي، أمان (دخول/استرداد/تغيير/خروج + قفل مؤقت)، نسخ احتياطي Export/Import.
- 3D اختياري (Three.js عبر CDN مع Fallback تلقائي)، حركات Reveal/Parallax/Tilt، دعم `prefers-reduced-motion`.
- أمان الواجهة: تعقيم كل المدخلات ضد XSS، تحقق من الروابط والملفات (نوع/امتداد/حجم، منع التنفيذيات)،
  أسماء ملفات آمنة، Rate Limiting للأزرار الحساسة وقفل الدخول بعد 5 محاولات.

## حدود النسخة المحلية (مهم)

- **البيانات في `localStorage` لهذا المتصفح فقط** — ليست متزامنة بين الأجهزة.
- الصور المرفوعة تُضغط وتُحفظ كـ DataURL محليًا (حد عملي ≈ 4–5MB إجمالًا حسب المتصفح، بحد أقصى 8MB للصورة
  و25MB للفيديو قبل المعالجة). عند الامتلاء تظهر رسالة تنبيه.
- التنبيه الصوتي يعمل في تبويب اللوحة المفتوح عبر `storage event` — وليس Push بين الأجهزة.
- زر WhatsApp يفتح رابط `wa.me` فقط (وليس WhatsApp API). للـ API الحقيقي يلزم Backend (انظر `.env.example`).
